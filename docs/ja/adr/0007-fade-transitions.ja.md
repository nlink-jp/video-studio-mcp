# ADR-0007: フェードはページ内ディップとして実装し、ページ間 xfade は採らない

- ステータス: Accepted
- 日付: 2026-07-26

## 背景

`transition` は v0.1.0 からマニフェストスキーマにあり、`fade` も受理値だった ——
が、それは前方互換のためだけで、実際は全ページ境界がハードカットで描画されていた
（ADR-0001 が非カットトランジションを「Phase 2」に先送りした）。マニフェストが
受理してから黙って無視するという、このサーバが他の箇所で
`DisallowUnknownFields` を使って防いでいるのと全く同じ失敗の形をしていた。

素朴な実装は ffmpeg の **`xfade`** フィルタ（ページ A を B にディゾルブする）だが、
ここでは誤った道具である。理由はパイプラインの中心的な不変条件にある。

`xfade` は2ページをトランジション長 `d` だけ**オーバーラップ**させる。この
オーバーラップは、このサーバが約束している事柄をそれぞれ壊す3つの帰結を持つ:

1. **総尺が音声尺の総和でなくなる。** `n` ページ・`k` 箇所フェードのデッキは
   `Σ音声 − k·d` になる。「各ページはその音声の長さちょうど表示されるので、A/V 同期は
   構成上厳密」（README, ADR-0001）が成り立たなくなり、しかもページ A が画面に残って
   いる間にページ B のナレーションが鳴り始める。
2. **チャプターとクローズドキャプションのタイムラインが壊れる。**
   `pageChapters` と `buildSRT` はどちらもページ音声尺の累積からタイムラインを導く。
   最初のフェード以降のすべてのマーカーが、累積オーバーラップ分ずれる。
3. **concat がストリームコピーできなくなる。** ADR-0001 の2段構成は、まさに結合を
   `-c copy` にするために各ページを同一パラメータでエンコードしている。ページ間の
   フィルタグラフはタイムライン全体の再エンコードを強制し、segment/concat 分割の
   意味が失われる。

## 決定

`transition: "fade"` を、**各ページ自身の尺の内側でキャンバス背景色へディップする**
形で描画する: ページ A は末尾 `d` でフェードアウトし、ページ B は先頭 `d` で
フェードインする。オーバーラップなし、セグメント跨ぎのフィルタグラフなし。

- **意味論。** ページ *i* の `transition` はページ *i+1* への境界を表す。そこの
  `fade` は、セグメント *i* 末尾のフェードアウト**と**セグメント *i+1* 先頭の
  フェードインを意味する。**最終ページ**では無視する —— 次の境界が存在しない。
  動画をフェードアウトで終わらせるのはアウトロであり別機能で、`transition` に
  両方の意味を持たせるとフィールドの意味が位置に依存してしまう。
- **位置。** 両フェードは `segmentArgs` の既存ページ内フィルタチェーンの、
  字幕オーバーレイの**後**に付ける。焼き込み字幕が暗くなる画像の上に浮いたままに
  ならず、ページと一緒にフェードする。
- **色。** ディップ先は `[video] background` —— レター/ピラーボックスのパディングと
  同じ色 —— なので黒以外のキャンバスでも整合する。
- **長さ。** `[video] fade_seconds`（既定 `0.5`）。レンダー単位では `master` の
  `fade_seconds` で上書き可能。**どのページも必ず半分以上は全輝度で残る**ように
  ページごとにクランプする: 1ページのフェード数 `n`（1 または 2）に対し、各フェードは
  `min(fade_seconds, 尺/2/n)`。結果が1フレーム（`1/fps`）未満になるフェードは落とす
  —— サブフレームのフェードはトランジションではない。
- **映像のみ。** 音声はフェードしない。ナレーションを削ってはならず、また音声
  ストリームこそがページの長さを定義するものである。
- **報告。** 結果に `fades_applied`（フェードとして描画した境界数）を載せる。
  `captions_burned` / `soft_caption_cues` と同じ趣旨。

## 帰結

- **不変条件はすべて保たれる。** ページ尺は依然 ffprobe 実測の音声長、総尺は依然
  `Σ音声`、チャプターと字幕のタイムラインはそのまま、最終 concat は依然 `-c copy`。
  変更は `segmentArgs` とそれを呼ぶページループに閉じている。
- **フェードはページ自身のナレーション時間を食う。** 0.5 秒フェードなら、ページ末尾
  0.5 秒の音声は暗くなる画像の上で、次ページ先頭 0.5 秒は明るくなる画像の上で鳴る。
  これはオーバーラップを拒んだ代価であり、正しい取引である: 視覚的ディップは
  装飾だが、音声タイムラインの破壊は欠陥である。気にするデッキは末尾に無音を
  持たせる（voice-studio-mcp のナレーションは通常そうなっている）か、
  `fade_seconds` を短くする。
- **本当のディゾルブは再エンコードなしには依然不可能。** 将来ページ間ディゾルブが
  必要になったら、独自の ADR、`fade` とは別の `crossfade` 値、音声タイムラインを
  どうするかの明示、そして第3のレンダー段が必要になる。今回の決定はそれを
  妨げない。
- **`fade` はもう嘘ではない。** マニフェストのフィールドは書いてある通りに動作し、
  ADR-0001 の「Phase 2」注記は本 ADR で置き換えられる。

## 検討した代替案

| 代替案 | 却下理由 |
|---|---|
| セグメント間 `xfade` | 総尺・チャプター/字幕タイムライン・copy concat を壊す（背景の項参照） |
| 映像と音声を両方フェード | フェードした全ページの両端でナレーションが削れる。音声長はページの契約である |
| `transition: "fade"` を未実装として拒否する | 正直ではあり実際に選択肢だった —— が、フィールドは公開スキーマに既にあり、ディップ対オーバーラップの問いが片付けば実装は安い |
| `background` を無視して常に黒へフェード | 白やブランド色のキャンバスで明らかにおかしい |
| 最終ページに末尾フェードを付ける | `transition` に位置依存の第2の意味を負わせる。将来のアウトロオプションの領分 |
