# ADR-0002: ページ単位のチャプターマーカー

- ステータス: Accepted
- 日付: 2026-07-05

## 背景

プレゼン動画は本質的にページで区切られているが、素の MP4 では視聴者がページ間を
頭出しできない。MP4/QuickTime チャプターを解釈するプレイヤー（QuickTime・IINA・
VLC・一部の Web プレイヤー。YouTube はタイムスタンプからチャプターを生成）は、
コンテナにチャプターマーカーがあればスライド単位のナビゲーションを提供できる。

マスタリングパイプライン（ADR-0001）は既にページごとの正確な尺（各セグメントは
`-t <probe済み音声尺>` で切る）を持ち、concat demuxer で連結している ——
`voice-studio-mcp` が m4b チャプターを ffmetadata で付ける場所と同じ。

## 決定

**1ページ1チャプター**を、既定 ON で付与する。

- **機構。** `;FFMETADATA1` ファイルにページごとの `[CHAPTER]` ブロック
  （`TIMEBASE=1/1000`、`START`/`END` は ms、`title=`）を書き、concat ステップの
  第2入力として `-map 0 -map_metadata 1`（全ストリームは concat 入力から、
  グローバルメタデータ=チャプターは ffmetadata 入力から）で渡す。`-c copy` の
  ストリームコピー連結と両立し、再エンコードしない。
- **境界。** ページごとの probe 済み音声尺の累積 —— 各セグメントの `-t` に使う
  値そのもの。追加の ffprobe 呼び出しなし。
- **タイトル。** マニフェスト任意 `title`。未指定なら `Page N`。（`title` は
  Phase 2 の `caption` とは意図的に別: チャプタータイトルは短いナビ用ラベル、
  caption は画面焼き込みの字幕テキスト。）
- **オプトアウト。** `master` ツールの `chapters`（既定 `true`）。

## 帰結

- **精度がタダ。** チャプター時刻は `-t` を駆動する probe 済み尺を再利用するので、
  境界はページ遷移に一致する。AAC フレーム/fps の量子化で実境界が1フレーム未満
  ずれ得るが、ナビゲーションでは不可視。
- **メタデータは信頼済み/サーバー書込。** ffmetadata は `output/tmp/` 配下で
  サーバーが生成するもの（エージェント入力ではない）ので、エージェント素材に
  適用する spawn 前 `VerifyRegular` チェックなしで ffmpeg に渡す。
- **マニフェスト新フィールド。** `title` が strict-decode スキーマに加わる。
  未知キーは従来どおり `invalid_manifest`。
- **コンテナ対応のみ。** チャプターは焼き込み映像でなくメタデータ。非対応
  プレイヤーは単に無視する。画面上のページタイトルが欲しい場合は別機能
  （Phase 2・caption 近辺）。
